# دفتر خرید ONE — اپ اندروید

یک اکتیویتی و یک WebView روی پنل زندهٔ `https://onecafe.beyondex.one`؛ نه فلاتر، نه Gradle، نه کتابخانه.
خروجی حدود ۳۳ کیلوبایت است و روی هر گوشی اندروید ۷ به بالا نصب می‌شود.

```bash
cd android-buyer
./build.sh          # → build/one-buying.apk
```

نیازمندی‌ها: Android SDK (build-tools 35، platform android-35) و JDK 17 — هر دو روی همین سیستم هست.

نصب روی گوشی: فایل APK را بفرست، گوشی اجازهٔ «نصب از منبع ناشناس» می‌خواهد، بعد نصب می‌شود.
کاربر یک‌بار وارد می‌شود و کوکی می‌ماند؛ دفعهٔ بعد مستقیم داخل پنل است.

فایل `one-buying.jks` کلید امضاست: **نگهش دار**. هر نسخهٔ بعدی باید با همین کلید امضا شود،
وگرنه گوشی اجازهٔ آپدیت روی نسخهٔ قبلی را نمی‌دهد.

اپ هیچ منطقی از خودش ندارد: هر چه پنل برای آن حساب اجازه بدهد، همان دیده می‌شود.
برای مسئول خرید یعنی دفتر خرید و (برای رستوران) رسپی‌ها.
